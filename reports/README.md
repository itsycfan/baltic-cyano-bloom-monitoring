# reports/

The authoritative, human-written record of the project — compiled once, after Confirm (see `docs/CHANGELOG.md`), from `docs/DEV_LOG.md` and `docs/RQ_MAPPING.md`. Anything else in this repository is supporting material for these two files, not a substitute for them.

Naming convention:

- `00_project_progress.pptx` — presentation, kept in sync with the full report.
- `01_full_report.docx` — the complete write-up, organized by RQ.
- `images/research_roadmap.png`, `images/technical_framework.png` — referenced from `docs/02_proposal.md` and the root `README.md`.

Superseded versions go to `../archive/`, not to a "(old version)" suffix here — and note *why* it was superseded in `docs/CHANGELOG.md`.
